# ABC Event-Driven Operations Demo

A static, S/4HANA Horizon-style design prototype for five event-driven operational approval scenarios.

## Live prototype

The GitHub Pages site serves [`prototype/index.html`](prototype/index.html). It requires no backend, framework, or build step.

## Local use

Open [`prototype/index.html`](prototype/index.html) directly in a browser. Use the gear menu or press **Shift+S** to open the scenario runner.

This is a design prototype with simulated data. No SAP system, event broker, or AI service is connected.
